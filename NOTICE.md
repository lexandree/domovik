# Notice

## Origin & Attribution

This standalone Linux repository combines work derived from two predecessor projects:

- [farzaa/clicky](https://github.com/farzaa/clicky), which contributed the original concept of an assistant companion that lives next to the cursor
- [Arnie936/zippy-windows](https://github.com/Arnie936/zippy-windows), which contributed the local-first Zippy direction, direct Anthropic and ElevenLabs API usage, local Whisper support, CLI handoff flows, and German trigger phrases

The current Linux runtime is a new platform adaptation built around Node.js and a browser UI rather than macOS AppKit or Windows WinForms.
